# Needoh-Factory
A game created for the Stardance Hackclub Challenge and to learn more about roblox game design.

## Play the Game
[click here to play the game](https://www.roblox.com/games/85070662876748/Needoh-Factory)

## Core Features
* Map made of islands in the water one for each plot and then a big map for the shops and other features
* exponential price scaling to keep the game playable
* decoration to make the game feel more firendly
* teleportation system to get around easier
* shop system work in progress
